# Bright Education Center (ASP.NET Core 8 MVC + EF Core + SQLite)

Run: open EducationCenter.csproj in Visual Studio and press F5 (or `dotnet run`).
The database file education.db and sample data are created automatically on first run.
If you change the models later, delete education.db so it is recreated.

Pages: / (home), /Courses, /Students, /Enrollments
CRUD: Courses and Students (Create, Read, Update, Delete with confirmation page), Enrollments.
Course status can be changed on the Details page or in Edit.
